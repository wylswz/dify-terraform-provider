# Changelog

All notable changes to this project are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- CI workflows for unit tests, lint, and generated-docs verification
- GoReleaser-based release workflow and `terraform-registry-manifest.json`
- `golangci-lint` configuration
- `docs/` website documentation generated by `tfplugindocs`, with runnable
  per-resource/data-source examples under `examples/`
- `CONTRIBUTING.md`, issue templates, and Dependabot configuration

## [0.1.0]

Initial release.

### Added

- Provider configuration via `host`, `token` (PAT), and `workspace_id`
- Resources: `dify_app`, `dify_app_api_key`, `dify_model_provider_credential`,
  `dify_model_credential`, `dify_default_model`, `dify_model_settings`,
  `dify_api_tool_provider`, `dify_mcp_provider`, `dify_workflow_tool`,
  `dify_tool_provider_credential`, `dify_plugin_install`
- Data sources: `dify_app`, `dify_models`, `dify_plugins`, `dify_tools`
- Automatic retry on HTTP 429 rate limiting and catalog-fingerprint refresh
